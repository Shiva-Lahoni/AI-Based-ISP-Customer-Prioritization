# AI-Based ISP Customer Prioritization

## Project Overview

Internet Service Providers (ISPs) often manage thousands of customers with different levels of business value. Providing premium support to every customer is not always feasible due to limited operational resources.

This project develops an AI-powered customer prioritization system that identifies the most valuable customers based on business-related features such as revenue, customer loyalty, strategic importance, and subscribed services.

---

## Business Problem

Customer value is not determined solely by monthly revenue.

Other important business factors include:

- Customer loyalty
- Internet bandwidth
- Monthly revenue
- VoIP services
- Server hosting services
- Strategic importance
- Customer type

The objective is to build an intelligent prioritization system that helps ISPs decide which customers should receive premium technical support and additional business services.

---

## Objectives

- Assess data quality
- Clean and preprocess the dataset
- Perform exploratory data analysis (EDA)
- Engineer business-oriented features
- Build a customer priority score
- Segment customers using unsupervised learning
- Generate business recommendations

---

## Dataset

This project uses a fully synthetic ISP customer dataset created exclusively for educational and portfolio purposes.

The dataset contains approximately 3,000 customer records including:

- Internet bandwidth
- Monthly internet fee
- Customer loyalty
- Customer type
- Strategic importance
- VoIP services
- Server hosting services
- Support history

## Privacy Notice
